# Lonestar Offer Creator

Windows app for Lonestar Cards: build customer buy offers from CardUploader, Collectr and TCGplayer exports, and print DYMO price labels.

**Download:** [latest version](releases/) — the newest `LonestarOfferCreator-x.y.z.exe` in the `releases` folder.

The app updates itself from this repository (Help → Check for updates). `latest.json` tells it which version is current; don't edit it by hand unless you're publishing an update.
